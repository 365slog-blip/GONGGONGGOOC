# 공주와 하이니

기존 웹 화면을 제공하고, 기록과 사진을 Notion에서 읽고 쓰는 Node 서버입니다.

## 배포

Node.js 24를 지원하는 HTTPS 호스팅에서 `node server.mjs`를 실행하거나 이 저장소의 Dockerfile로 배포합니다. 세션을 서버에 보관하므로 하나의 서버 인스턴스로 실행하세요. 재시작하면 다시 로그인해야 합니다.

다음 값을 호스팅의 비공개 환경 변수로 설정합니다.

| 이름 | 값 |
| --- | --- |
| `PUBLIC_ORIGIN` | 공개 HTTPS 주소의 origin. 예를 들어 `https://example.com` |
| `NOTION_TOKEN` | Notion 내부 연결 토큰 |
| `NOTION_DATA_SOURCES` | 시트 기록 아래의 데이터베이스 이름과 데이터 소스 ID를 짝지은 JSON 객체. 이름은 `notion-tables.json`과 일치해야 합니다. |
| `APP_USERS` | 아이디를 키로 하는 JSON 객체. 각 계정에 `password`(16자 이상)와 `role`(`editor` 또는 `reader`)을 설정합니다. |
| `SESSION_SECRET` | 세션 서명에 사용할 임의의 32자 이상 비밀값 |
| `PORT` | 호스팅이 지정하는 포트. 기본값 3000 |

Notion에서 내부 연결을 만든 뒤 **시트 기록**에 연결을 추가하고 읽기, 수정, 추가 권한을 켜세요. 메인 페이지나 사진 보관함을 공개할 필요는 없습니다. 사이트에 로그인하는 사람은 Notion 계정 없이 앱의 권한에 따라 기록을 읽거나 수정할 수 있습니다.

기존 주소를 연결하기 전에 새 HTTPS 주소에서 두 계정으로 로그인해 권한을 확인하고, 노션에서 기록 조회·수정, 사진 추가·열기, 삭제가 반영되는지 확인하세요. 기존 GitHub Pages 주소는 확인 후 새 주소로 연결할 수 있습니다.
